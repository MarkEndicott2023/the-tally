Sessions

A rep is one prediction-error cycle: attempt or predict, get the verdict, take the feedback. Every click is one point. The session closes when points reach the threshold; keep clicking past it if you like. Label names the session (optimization, big data, python…) and is filed with it; click a filed label to rename it, ✕ deletes the session. New session files the current count and resets to zero. Save links the page to a tally.json you choose: it reads what the file already holds, merges, writes, and from then on every change goes to the file, deletes included.
